### Quick Reference Rules

1. **Single-Gate Approval & Autonomous Execution**: Drop the implementation plan and wait for the user's response to proceed. Once approved, execute all commands, edits, and tests autonomously without asking for micro-permissions.
2. **Verify Before Declaring Complete**: Always run automated tests or linter checks after making modifications.
3. **Atomic Commits**: Keep Git changes organized and clearly described.
4. **Progressive Skill Activation**: Refer to the skills library in `../Skills/` for domain-specific runbooks.
